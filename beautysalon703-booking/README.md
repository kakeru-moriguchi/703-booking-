# ビューティーサロン703 予約システム

ビューティーサロン703 の予約専用Webアプリです。
公式LINEのリッチメニュー「予約」から開く運用を想定しています（スマートフォン最優先）。

既存のホームページ（Vercel の `703` プロジェクト）とは**完全に別のプロジェクト**です。
稼働中の Amulea 予約システム（`amulea-booking`）を土台に作っています。
配色・書体・ロゴはホームページと同じ（Botanical / Sage / Mustard / Ivory）です。

---

## できること

### お客様

- 空いている日時だけを見て予約する（埋まっている時間は表示されません）
- 予約内容の確認・日時の変更・キャンセル
- 予約完了・変更・キャンセルの LINE 通知を受け取る

### 管理者（`/admin`）

- 本日の予約数・次の予約・売上予定をひと目で確認
- 予約の一覧・詳細（電話番号・ご要望まで確認できます）
- 電話で受けた予約の手動登録・変更・キャンセル
- 日別カレンダー（Googleカレンダーの私用予定も表示）
- **メニュー・オプションの追加・編集・並べ替え・削除（料金・所要時間・説明文）**
- **営業時間（平日／土日祝）・最終受付・準備時間・定休日・臨時休業日・受付停止**
- **LINE通知のオン／オフ**
- **接続診断**（Google・LINE のどこで止まっているかと直し方を表示）

日本の祝日（振替休日・国民の休日を含む）は自動で判定されます。

## 本番で使うまでの流れ

```
STEP 1  Vercel に公開する                 → docs/SETUP-VERCEL.md（15〜20分）
STEP 2  管理画面でメニュー・営業時間を登録する   （管理画面 → 設定）
STEP 3  Google 連携を設定する             → docs/SETUP-GOOGLE.md（20〜30分）
STEP 4  LINE 連携を設定する               → docs/SETUP-LINE.md（30〜40分）
STEP 5  管理画面「接続を確認する」がすべて ✅ になったら本番開始
```

各連携は **その連携の認証情報が揃った時点で、その連携だけ** が有効になります。
「全部まとめて切り替えるスイッチ」はありません。途中の段階でも動き続けます。

| 設定したもの | 起きること |
| --- | --- |
| （何も設定しない） | メモリ上だけで全機能が動く（お試し。再起動でデータが消える） |
| `ADMIN_PASSWORD_HASH` | 開発用の初期パスワードが使えなくなる |
| Google カレンダーの値 | カレンダーへの予約書き込み・私用予定の反映・二重予約防止が有効 |
| スプレッドシートの値 | 予約データ・設定がスプレッドシートに保存される |
| LINE ログインの値 | LINE で本人確認。**開発用の仮ログインが自動的に閉じる** |
| LINE 通知の値 | お客様・管理者への通知が送られる |

準備が済んでいない項目は、管理画面の上部に表示されます（設定が済むと自動で消えます）。

## 管理画面でまず行うこと

1. `https://（公開URL）/admin` を開き、ログインします
   （初期値 ID: `admin` ／ パスワード: `salon703-dev`）。
2. 赤字の警告 **「開発用の初期パスワードのままです」** → **初期設定の値づくり** から
   パスワードを変更します（手順は docs/SETUP-VERCEL.md の手順5〜6）。
3. **設定** を開きます。
4. **メニューと料金** → **＋ メニューを追加** で、メニューを登録します。
   メニュー名・説明文・所要時間・料金（税込）・分類を入力し、**メニューを保存する** を押します。
   > 💡 メニューの初期値は「空」です（正式メニュー未確定のため、架空のメニューを出さないようにしています）。
   > メニューが1件も無いあいだ、お客様の画面には「準備中」と電話番号が表示されます。
5. オプションがあれば **オプション** → **＋ オプションを追加** で登録します。
   無ければ空のままで構いません（予約画面のオプション選択が自動で省略されます）。
6. **営業時間** を確認します。初期値は次のとおりです。

   | | 開店 | 最終受付 | 閉店 |
   | --- | --- | --- | --- |
   | 平日（月〜金） | 7:00 | 20:00（仮） | 21:00 |
   | 土・日・祝 | 7:00 | 20:00（仮） | 21:00 |

7. **定休日**（曜日）、**予約枠と準備時間**（0/15/30/45/60分）を選び、
   **設定を保存する** を押します。

### 「最終受付」の意味

**最終受付は「施術を始められる最後の時刻」**です。ただし**閉店時刻を超えるメニューは受け付けません。**

- 最終受付 20:00・閉店 23:00 → 20:00 開始の120分（22:00 終了）は **予約できる**
- 最終受付 20:00・閉店 21:00 → 20:00 開始の120分（22:00 終了）は **予約できない**／60分なら予約できる

準備時間を設定した場合は、準備時間を含めた枠で重なりを判定します。

## 日々の運用

| やりたいこと | 方法 |
| --- | --- |
| その日を休業にする | Google カレンダーに**終日**の予定を入れる ／ 管理画面 **設定 → 臨時休業日** |
| 一部の時間だけ止める | Google カレンダーに予定を入れる ／ **設定 → 予約受付を止める時間帯** |
| 予約をすべて止める | **設定 → 予約の受付** をオフ |
| 料金・メニューを変える | **設定 → メニューと料金**（過去の予約の金額は変わりません） |
| 通知を止める | **設定 → LINE通知** |

---

## うまくいかないとき

1. 管理画面の **設定 → 接続を確認する** を押す（管理者向け診断）
   - Google・LINE・パスワード・署名鍵を順番に確認し、止まっている場所と直し方を表示します
   - JSON の貼り間違い・`private_key_id` との取り違え・LIFF ID とチャネルIDの不一致も名指しします
2. LINE アプリ内で開けない・戻されるときは、スマートフォンで `https://（公開URL）/check` を開く（お客様向け診断）
   - LINE アプリ内ブラウザで何が起きているかを順番に表示します（自動で別の画面に移動しません）

## よくある質問

**Q. 既存のホームページに影響はありますか？**
A. ありません。別のプロジェクト・別のURLで動きます。

**Q. 同時に2人が同じ時間を予約したらどうなりますか？**
A. 必ず1人だけが成立します。もう1人には
「申し訳ありません。この時間は先ほど他のお客様の予約が入りました。別のお時間をお選びください。」
と表示され、時間の選び直しに戻ります。（docs/ARCHITECTURE.md の「8.」）

**Q. 他のお客様の予約は見えてしまいませんか？**
A. 見えません。URLの予約IDを書き換えても、サーバー側で本人確認を行います（docs/SECURITY.md）。

**Q. Google カレンダーにお客様の名前は載りますか？**
A. 載りません。予定名は「ビューティーサロン703予約｜メニュー名」だけです。

## 開発者向け

### コマンド

```bash
cd beautysalon703-booking
npm install
npm run dev         # 開発サーバー（http://localhost:3000）
npm run build       # 本番ビルド
npm run typecheck   # 型チェック
npm test            # 自動テスト（Node 標準のテスト機能のみ・追加ライブラリなし）
```

手元で `.env.local` を使う場合は `cp .env.example .env.local` で作成します（Git には登録されません）。

### 技術構成

TypeScript 5.9 / Next.js 16.3（App Router）/ React 19.1 / Tailwind CSS 4
**外部ライブラリは追加していません。** Google・LINE 連携は Node 標準の `node:crypto` と `fetch` だけで実装しています。
書体もウェブフォントを使わず、ホームページと同じく端末の書体を使います。
