# LINE 連携の設定手順

公式LINEから予約ページを開けるようにし、
予約完了・変更・キャンセルの通知を LINE で送れるようにします。

- **かかる時間**: 30〜40分ほど
- **費用**: 無料プランの範囲で始められます（通知の送信数に上限があります）
- **必要なもの**: ビューティーサロン703 の公式LINEを管理している LINE アカウント

> 💡 公式LINEアカウントがまだ無い場合は、先に <https://www.linebiz.com/jp/entry/> から
> 「LINE公式アカウント」を無料で開設してください（サロン名で作成します）。

> **先に読んでください**
> LINE の設定は、**2種類のチャネル**を作るところが少しややこしい部分です。
> それぞれ役割が違うので、下の表を頭に入れてから進めると迷いません。

| チャネル | 役割 | 例えるなら |
| --- | --- | --- |
| **LINE ログイン** チャネル | 「今開いているのが誰か」を知る | 入口の受付 |
| **Messaging API** チャネル | お客様や管理者へメッセージを送る | 郵便屋さん |

ビューティーサロン703 の公式LINE が Messaging API チャネルになります。
LINE ログインチャネルは、これから新しく作ります。

---

## 全体の流れ

```
手順1  LINE Developers にログインする
手順2  LINE ログインチャネルを作る
手順3  LIFF（予約ページの入口）を登録する
手順4  公式LINE（Messaging API）のトークンを取得する
手順5  2つのチャネルを同じプロバイダーにまとめる
手順6  管理者の LINE userId を調べる
手順7  Vercel に登録する
手順8  LINEログインチャネルを「公開」に切り替える　★忘れやすい
手順9  リッチメニューに予約ページを設定する
```

---

## 手順1　LINE Developers にログインする

1. ブラウザで <https://developers.line.biz/console/> を開きます。
2. **LINEアカウントでログイン** をクリックし、
   サロンの公式LINE を管理しているアカウントでログインします。
3. 初回は開発者登録の画面が出ます。名前とメールアドレスを入力して進みます。

ログインすると **プロバイダー** という一覧が表示されます。
プロバイダーとは「サービスをまとめる箱」のことです。
すでに `ビューティーサロン703` のような名前の箱があれば、それを使います。
なければ **作成** から `ビューティーサロン703` という名前で1つ作ってください。

---

## 手順2　LINE ログインチャネルを作る

1. 手順1のプロバイダー（`ビューティーサロン703`）をクリックして開きます。
2. **新規チャネル作成** をクリックします。
3. チャネルの種類から **LINEログイン** を選びます。
4. 次のように入力します。

   | 項目 | 入力する内容 |
   | --- | --- |
   | チャネル名 | `ビューティーサロン703 予約` |
   | チャネル説明 | `ビューティーサロン703の予約システム` |
   | アプリタイプ | **ウェブアプリ** にチェック |
   | メールアドレス | ご自身のメールアドレス |

   > ⚠️ チャネル名に「LINE」という文字は使えません。

5. 利用規約に同意して **作成** をクリックします。

### チャネルIDをメモする

作成後、**チャネル基本設定** タブを開きます。
**チャネルID**（10桁ほどの数字）をメモしてください。

```
LINE_LOGIN_CHANNEL_ID=1234567890   ← これ
```

---

## 手順3　LIFF を登録する

LIFF は「LINEの中で開くWebページ」の登録です。

1. いま作った `ビューティーサロン703 予約` チャネルの **LIFF** タブを開きます。
2. **追加** をクリックします。
3. 次のように入力します。

   | 項目 | 入力する内容 |
   | --- | --- |
   | LIFFアプリ名 | `ビューティーサロン703 予約` |
   | サイズ | **Full**（画面いっぱい） |
   | エンドポイントURL | 後述（下を読んでください） |
   | Scope | **profile** と **openid** の両方にチェック |
   | ボットリンク機能 | **On (Aggressive)** |

### エンドポイントURLについて

ここには**予約ページの公開URL**を入れます。

- **まだ公開していない場合**: とりあえず `https://example.com` を入れて
  作成し、Vercel へ公開したあとに正しいURLへ書き換えてください。
- **公開済みの場合**: `https://beautysalon703-booking.vercel.app` のように、
  実際のURLを入れます（末尾のスラッシュは不要）。

> ⚠️ **エンドポイントURLは「トップページ」にしてください**
> `/booking` などのサブページにしないでください。
> LINE は認証が終わると、必ずこのエンドポイントURLへお客様を戻します。
> この予約システムは「トップページでLINEログインを済ませる」作りになっているため、
> ここがトップページでないと「予約を押したのにホームに戻される」状態になります。

4. **追加** をクリックします。

### LIFF IDをメモする

作成すると **LIFF ID**（`1234567890-abcdefgh` のような形式）が
表示されます。これをメモしてください。

```
NEXT_PUBLIC_LIFF_ID=1234567890-abcdefgh   ← これ
```

> 💡 **LIFF ID は公開されても問題ありません。**
> これだけはブラウザにも渡されますが、これ単体では何もできません。
> 危険なのは次の手順で扱う「アクセストークン」のほうです。

---

## 手順4　公式LINE（Messaging API）のトークンを取得する

通知を送るための鍵を取得します。

1. LINE Developers の一覧から、
   **ビューティーサロン703 の公式LINE**（Messaging API チャネル）を開きます。

   > 見当たらない場合は、公式LINE を
   > [LINE Official Account Manager](https://manager.line.biz/) で開き、
   > **設定 → Messaging API → Messaging APIを利用する**
   > を先に済ませてください。

2. **Messaging API設定** タブを開きます。
3. いちばん下の **チャネルアクセストークン（長期）** を探します。
4. **発行** をクリックします。
5. 表示された長い文字列をコピーしてメモします。

```
LINE_MESSAGING_CHANNEL_ACCESS_TOKEN=（とても長い文字列）
```

> 🔐 **このトークンの扱い**
> これが漏れると、**誰でもサロンの名前でお客様へLINEを送れてしまいます。**
> - 誰にも見せないでください
> - GitHub には絶対に登録しないでください
> - 漏れた疑いがあれば、この画面で **再発行** すれば古いものは無効になります

### 応答設定も確認しておきます

同じ **Messaging API設定** タブで、次のようにしておくと運用しやすくなります。

| 項目 | 推奨 |
| --- | --- |
| 応答メッセージ | **オフ**（自動返信を止める） |
| あいさつメッセージ | お好みで |
| Webhook | 使わないので **オフ** のままでOK |

---

## 手順5　2つのチャネルを同じプロバイダーにまとめる

**この手順は重要です。**

LINE ログインチャネルと Messaging API チャネルが
**同じプロバイダー**の中にないと、
「予約したお客様へ通知を送る」ことができません。

1. LINE Developers のトップで、両方のチャネルが
   同じプロバイダー（`ビューティーサロン703`）の下にあるか確認します。
2. 別々になっている場合は、LINE ログインチャネルの
   **チャネル基本設定** → いちばん下の **プロバイダー** から移動できます。

### 友だち追加も必須です

お客様に通知が届くのは、**サロンの公式LINEを友だち追加している方だけ**です。
公式LINEのリッチメニューから予約する運用であれば、
必ず友だち追加済みなので問題ありません。

---

## 手順6　管理者の LINE userId を調べる

新規予約の通知を受け取るために、ご自身の **userId** が必要です。
userId は `U` から始まる33文字の英数字です（LINE ID や表示名とは別物です）。

1. LINE Developers で、**手順4の Messaging API チャネル**を開きます。
2. **チャネル基本設定** タブを開きます。
3. いちばん下のほうにある **あなたのユーザーID** の欄の値をコピーします。

```
LINE_ADMIN_USER_IDS=U1234567890abcdef1234567890abcdef
```

> ⚠️ 管理者ご本人も、サロンの公式LINEを**友だち追加**しておいてください。
> 友だちでない相手には通知が届きません。

複数の方に通知したい場合は、カンマで区切ります（例: `U1111...,U2222...`）。
他のスタッフの userId は、その方が予約システムで1件予約すると
スプレッドシートの `LINE userId` 列に記録されるので、そこから確認できます。

---

## 手順7　Vercel に登録する

これまでメモした値を、Vercel に登録します。

1. <https://vercel.com/> にログインし、`beautysalon703-booking` プロジェクトをクリックします。
2. 上部のタブから **Settings** をクリックします。
3. 左側のメニューから **Environment Variables** をクリックします。
4. 次の4つを、1つずつ登録します。
   **Key** 欄に左側の名前、**Value** 欄に右側の値を貼り、**Save** をクリックします。

   | Key | Value |
   | --- | --- |
   | `NEXT_PUBLIC_LIFF_ID` | 手順3の LIFF ID（例 `1234567890-abcdefgh`） |
   | `LINE_LOGIN_CHANNEL_ID` | 手順2の **LINEログイン** チャネルのチャネルID（数字） |
   | `LINE_MESSAGING_CHANNEL_ACCESS_TOKEN` | 手順4の長いトークン |
   | `LINE_ADMIN_USER_IDS` | 手順6の userId |

   > ⚠️ `LINE_LOGIN_CHANNEL_ID` には **LINEログイン** チャネルのIDを入れます。
   > Messaging API チャネルのIDではありません。
   > （LIFF ID の「-」より前の数字と同じになるはずです。
   > 　違う場合は管理画面の接続診断が教えてくれます）

5. 上部の **Deployments** タブ → いちばん上の行の右端 **⋯** → **Redeploy** → **Redeploy** をクリックします。

   > ⚠️ 環境変数は登録しただけでは反映されません。必ず Redeploy してください。

6. Redeploy が終わったら、管理画面の **設定 → 接続を確認する** を押します。
   【LINE】の行が ✅ になっていれば成功です。

> 💡 LINEログインの設定が揃った時点で、開発用の「仮ログイン」は**自動的に閉じます**。
> 管理画面上部の赤字「どなたでも仮のお客様としてログインできる状態です」も消えます。

---

## 手順8　LINEログインチャネルを「公開」に切り替える　★忘れやすい

作ったばかりの LINEログインチャネルは **「開発中」** という状態です。
このままだと、**開発者（あなた）以外のお客様が開くと次のエラーになります。**

```
400 Bad Request
This channel is now developing status. User need to have developer role.
```

1. LINE Developers で、手順2の **LINEログイン** チャネル（`ビューティーサロン703 予約`）を開きます。
2. 画面上部、チャネル名の横にある **「開発中」** という表示をクリックします。
3. **公開** をクリックします。
4. 確認の画面で、もう一度 **公開** をクリックします。
5. 表示が **「公開済み」** に変われば完了です。

> 💡 ご自身のスマートフォンでは動くのに、お客様から「400 Bad Request と出る」と
> 言われた場合は、ほぼ間違いなくこの手順が抜けています。

---

## 手順9　リッチメニューに予約ページを設定する

最後に、公式LINEの「予約」ボタンから
予約ページが開くようにします。

1. [LINE Official Account Manager](https://manager.line.biz/) を開きます。
2. ビューティーサロン703 の公式LINEを選びます。
3. 左メニューの **トークルーム管理** → **リッチメニュー** を開きます。
4. 既存のリッチメニューを選ぶか、新規に作成します。
5. 「予約」の領域をクリックし、アクションを設定します。

   | 項目 | 設定する内容 |
   | --- | --- |
   | アクション | **リンク** |
   | URL | `https://liff.line.me/1234567890-abcdefgh` |
   | アクションラベル | `予約` |

   > ⚠️ **URLに注意**
   > `https://beautysalon703-booking.vercel.app` ではなく、
   > **`https://liff.line.me/【LIFF ID】`** を設定してください。
   >
   > こうすることで LINE アプリ内のブラウザで開き、
   > お客様がログイン操作をせずに予約できます。
   > 直接のURLだと、毎回ログインが必要になってしまいます。

6. **保存** をクリックします。

---

## 動作確認

1. ご自身のスマートフォンで サロンの公式LINEを開きます。
2. リッチメニューの **予約** をタップします。
3. 予約ページが開けば成功です。
4. 実際に1件予約してみます。
5. 予約完了後、**LINEに通知が届けば成功**です。
   - お客様向け通知（ご自身宛）
   - 管理者向け通知（`LINE_ADMIN_USER_IDS` に設定した宛先）
6. 確認できたら、テスト予約はキャンセルしてください。

---

## うまくいかないとき

| 症状 | 原因と対処 |
| --- | --- |
| 「LINEとの連携に失敗しました」と出る | LIFF のエンドポイントURLが、実際の公開URLと違います。手順3で修正してください |
| ログイン画面がぐるぐる回り続ける | Scope の **openid** にチェックが入っているか確認してください |
| 予約はできるが通知が来ない | ①`LINE_MESSAGING_CHANNEL_ACCESS_TOKEN` が正しいか ②公式LINEを友だち追加しているか ③2つのチャネルが同じプロバイダーにあるか |
| 管理者にだけ通知が来ない | `LINE_ADMIN_USER_IDS` の userId が違います。手順6で確認し直してください |
| お客様だけ「400 Bad Request」「This channel is now developing status」と出る | LINEログインチャネルが「開発中」のままです。**手順8**で「公開」にしてください |
| 「予約する」を押すとトップページに戻される | LIFF のエンドポイントURLがトップページ以外になっています。手順3で**トップページのURL**にしてください |
| リンクを押しても何も起きない | 予約ページのアドレスで `/check` を開くと、LINEアプリ内で何が起きているかを順番に表示します。その画面をスクリーンショットして開発者に送ってください |
| ブラウザで開くと毎回ログインを求められる | リッチメニューのURLが `liff.line.me` 形式になっているか確認してください |

通知の送信に失敗しても、**予約そのものは成立します**。
「予約はできたのに通知が来ない」という状態になった場合は、
管理画面で予約が入っているかを確認してください。

---

## 通知内容について（個人情報の扱い）

安全のため、LINE通知には最小限の情報しか載せていません。

| 情報 | お客様への通知 | 管理者への通知 |
| --- | --- | --- |
| 日時・メニュー・料金 | ✅ 載せる | ✅ 載せる |
| お名前 | ❌ 載せない | ✅ 載せる |
| 電話番号 | ❌ 載せない | ❌ 載せない |
| 自由記載 | ❌ 載せない | ❌ 載せない（「記載あり」とだけ表示） |

電話番号と自由記載は、**管理画面でのみ**確認できます。
LINEのトーク画面は他の人に見られる可能性があるため、
このような設計にしています。

文面を変えたい場合は `lib/line/messages.ts` を編集してください。
