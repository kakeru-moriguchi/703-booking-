# Google 連携の設定手順

Google カレンダーとスプレッドシートに、予約を自動で書き込めるようにします。

- **かかる時間**: 20〜30分ほど
- **費用**: 無料（この規模の利用では料金は発生しません）
- **必要なもの**: サロンの予定を管理している Google アカウント（例: `beautysalon703.naomi@gmail.com`）にログインできる状態

> 💡 まだ専用の Google アカウントが無い場合は、先に <https://accounts.google.com/signup> で作成してください。
> 以下、この手順書では「サロンの Google アカウント」と呼びます。

> **先に読んでください**
> 途中で分からなくなっても、設定を間違えても、壊れることはありません。
> この設定をしなくても予約システムは動きます（カレンダー連携が働かないだけです）。
> 落ち着いて1つずつ進めてください。

---

## 全体の流れ

```
手順1  Google Cloud にプロジェクトを作る
手順2  カレンダーとシートの機能をONにする
手順3  「サービスアカウント」という専用アカウントを作る
手順4  鍵ファイル（JSON）をダウンロードする
手順5  カレンダーを、そのアカウントに共有する
手順6  スプレッドシートを作り、同じく共有する
手順7  取得した値を Vercel に登録する
```

「サービスアカウント」とは、**人ではなくプログラム専用の Google アカウント**
のことです。これを作って、自分のカレンダーを「共有」してあげることで、
予約システムがカレンダーを読み書きできるようになります。

---

## 手順1　Google Cloud にプロジェクトを作る

1. サロンの Google アカウントで Google にログインします。
2. ブラウザで <https://console.cloud.google.com/> を開きます。
3. 初回は利用規約の同意画面が出ます。同意して進みます。
4. 画面いちばん上の、青いバーの左側にある
   **プロジェクトを選択** をクリックします。
5. 右上の **新しいプロジェクト** をクリックします。
6. プロジェクト名に `beautysalon703-booking` と入力します。
7. **作成** をクリックします。
8. 数十秒で作成されます。画面上部が `beautysalon703-booking` に
   変わっていることを確認してください。

> ⚠️ **ここで一度確認**
> 以降の作業は、必ず `beautysalon703-booking` プロジェクトが
> 選ばれている状態で行ってください。
> 画面上部の表示が違っていたら、クリックして切り替えます。

---

## 手順2　カレンダーとシートの機能をONにする

Google では、使いたい機能を1つずつONにする必要があります。

### カレンダー

1. 上部の検索窓に `Google Calendar API` と入力します。
2. 検索結果の **Google Calendar API** をクリックします。
3. 青い **有効にする** ボタンをクリックします。
4. 「APIが有効です」と表示されればOKです。

### スプレッドシート

1. 同じく検索窓に `Google Sheets API` と入力します。
2. **Google Sheets API** をクリックします。
3. **有効にする** をクリックします。

---

## 手順3　サービスアカウントを作る

1. 左上の **≡（三本線）** →
   **APIとサービス** → **認証情報** を開きます。
2. 上部の **＋ 認証情報を作成** をクリックします。
3. 一覧から **サービス アカウント** を選びます。
4. 次のように入力します。

   | 項目 | 入力する内容 |
   | --- | --- |
   | サービス アカウント名 | `beautysalon703-booking` |
   | サービス アカウント ID | 自動で入ります。そのままでOK |
   | 説明 | `予約システム用`（空欄でも可） |

5. **作成して続行** をクリックします。
6. 「ロールを選択」は **何も選ばずに** **続行** をクリックします。
   （カレンダーの権限は、あとで「共有」で渡すためです）
7. 最後の画面も **完了** をクリックします。

---

## 手順4　鍵ファイル（JSON）をダウンロードする

1. **認証情報** の画面に、作ったサービスアカウントが
   一覧で表示されています。
2. そのメールアドレス（`beautysalon703-booking@beautysalon703-booking-XXXXXX.iam.gserviceaccount.com`
   のような長いもの）をクリックします。
3. 上部のタブから **キー** を選びます。
4. **鍵を追加** → **新しい鍵を作成** をクリックします。
5. キーのタイプは **JSON** を選び、**作成** をクリックします。
6. `beautysalon703-booking-xxxxx.json` というファイルが
   パソコンにダウンロードされます。

> 🔐 **このファイルの扱い**
> このファイルは**家の鍵と同じ**です。
> - 誰にも送らないでください（メール・LINE・チャットすべてNG）
> - Git（GitHub）には**絶対に**登録しないでください
> - 設定が終わったら、パソコンから削除して構いません

7. **サービスアカウントのメールアドレスを、メモ帳などにコピーしておいてください。**
   次の手順で使います。

---

## 手順5　カレンダーを共有する

作ったサービスアカウントに、カレンダーを見る・書く権限を渡します。

1. <https://calendar.google.com/> を開きます
   （サロンの Google アカウントでログインした状態で）。
2. 画面左の「マイカレンダー」から、予約を入れたいカレンダーを探します。
   通常は **あなたのお名前** のカレンダーです。
3. そのカレンダー名にマウスを乗せ、右に出る **⋮（縦三点）** をクリック。
4. **設定と共有** を選びます。
5. 下へスクロールして **特定のユーザーまたはグループと共有する** を探します。
6. **＋ ユーザーやグループを追加** をクリックします。
7. 手順4でメモした**サービスアカウントのメールアドレス**を貼り付けます。
8. 権限は **予定の変更権限** を選びます。

   > ⚠️ 「閲覧権限」では予約を書き込めません。
   > 必ず **予定の変更権限** を選んでください。

9. **送信** をクリックします。

### カレンダーIDを確認する

同じ「設定と共有」の画面を下へスクロールすると
**カレンダーの統合** という項目があります。
そこにある **カレンダー ID** をメモしてください。

ご自身のメインカレンダーであれば、
**そのGoogleアカウントのメールアドレス**（例: `beautysalon703.naomi@gmail.com`）がそのままカレンダーIDです。

---

## 手順6　スプレッドシートを作って共有する

1. <https://sheets.google.com/> を開きます。
2. **空白のスプレッドシート** をクリックして新規作成します。
3. 左上のファイル名を `ビューティーサロン703 予約データ` に変更します。
4. 右上の **共有** ボタンをクリックします。
5. 手順4でメモした**サービスアカウントのメールアドレス**を貼り付けます。
6. 権限は **編集者** を選びます。
7. 「通知を送信」のチェックを**外して**、**共有** をクリックします。

### スプレッドシートIDを確認する

ブラウザのURLを見てください。

```
https://docs.google.com/spreadsheets/d/1AbCdEfGhIjKlMnOpQrStUvWxYz1234567890/edit
                                      └──────────── ここがID ────────────┘
```

`/d/` と `/edit` のあいだの長い文字列がIDです。これをメモします。

> 💡 シートのタブや見出し行は、**予約システムが自動で作ります**。
> 何も準備しなくて大丈夫です。

---

## 手順7　4つの値を登録する

ここまでで集めた4つの値を、アプリに教えます。

**登録する場所は、動かしている環境によって変わります。**

### 🌐 Vercel で公開している場合（通常はこちら）

`.env.local` というファイルは**作りません**。Vercel の画面に登録します。

1. Vercel で `beautysalon703-booking` プロジェクトを開く
2. 上部のタブから **Settings** をクリック
3. 左側のメニューから **Environment Variables** をクリック
4. **Key** 欄に名前、**Value** 欄に値を入れ、**Environments** は
   **Production・Preview・Development** のすべてにチェックが入った状態で **Save**
   （下の「登録する値」を1つずつ登録します）
5. すべて登録したら **Deployments** タブ →
   一番上の行の右端 **⋯** → **Redeploy** → もう一度 **Redeploy**

   > ⚠️ 環境変数は登録しただけでは反映されません。必ず Redeploy してください。

### 💻 パソコンで動かしている場合

プロジェクトのフォルダにある `.env.example` をコピーして
`.env.local` という名前のファイルを作ります。

```bash
cp .env.example .env.local
```

`.env.local` をテキストエディタで開いて埋めます。

---

### 登録する値

**いちばん簡単な方法（おすすめ）** と、従来の方法があります。

---

## 【おすすめ】JSONを丸ごと貼る方式（3つだけ）

秘密鍵は数千文字あり、「-----BEGIN から -----END まで」を正確に選ぶのは
とても失敗しやすい作業です。**その工程をなくせます。**

### ① GOOGLE_SERVICE_ACCOUNT_JSON

1. ダウンロードした JSON ファイルをメモ帳で開く
   （右クリック →「プログラムから開く」→「メモ帳」）
2. **Ctrl + A**（全選択）→ **Ctrl + C**（コピー）
3. Vercel の Value 欄に **Ctrl + V** で貼る
4. Type は **Secret** にする

これだけで、**メールアドレスと秘密鍵の両方**が設定されます。
`GOOGLE_CLIENT_EMAIL` と `GOOGLE_PRIVATE_KEY` は不要です。

> 💡 すでに `GOOGLE_CLIENT_EMAIL` を登録済みでも構いません。
> JSON があるときは JSON の中身が優先されます。
> （メールアドレスと秘密鍵は必ず対になっている必要があるため、
> 　バラバラに設定されたものより JSON のほうが確実です）

### ② GOOGLE_CALENDAR_ID

```
beautysalon703.naomi@gmail.com
```
（手順5で確認したカレンダーIDを入れてください。上は例です）

### ③ GOOGLE_SPREADSHEET_ID

手順6でメモしたIDです。

```
1AbCdEfGhIjKlMnOpQrStUvWxYz1234567890
```

---

## 【従来の方法】1つずつ設定する（4つ）

JSONを丸ごと貼れない場合はこちらでも設定できます。

### ① GOOGLE_CLIENT_EMAIL

手順4でメモしたメールアドレスです。

```
beautysalon703-booking@あなたのプロジェクト名.iam.gserviceaccount.com
```

> ⚠️ **手順書の記入例をそのまま貼らないでください。**
> ご自身のサービスアカウントのメールアドレスを使ってください。
> Google Cloud の「サービス アカウントの詳細」画面の「メール」欄で確認できます。

### ② GOOGLE_PRIVATE_KEY

JSONファイルをメモ帳で開き、`Ctrl + F` で `private_key` を検索します。

> ⚠️ **よくある間違い**
> JSONの中には、よく似た名前の項目が**2つ並んでいます**。
>
> ```json
> "private_key_id": "3faca8a2567ab57...",          ← ❌ こちらではありません
> "private_key": "-----BEGIN PRIVATE KEY-----\n...",  ← ✅ こちらです
> ```
>
> 検索すると **`private_key_id` のほうが先に見つかります。**
> 必ず、**`-----BEGIN PRIVATE KEY-----` で始まる長いほう**を使ってください。
> （この取り違えを防ぐため、上の「JSONを丸ごと貼る方式」を推奨しています）

```json
"private_key": "-----BEGIN PRIVATE KEY-----\nMIIEvQIBADAN...\n-----END PRIVATE KEY-----\n",
```

**`-----BEGIN` から `-----END PRIVATE KEY-----\n` まで**をコピーします。

> 💡 **`\n` はそのままでOK**（改行の記号です。手で直さないでください）
> 💡 前後の `"` を含めても、空白が混ざっても動くようにしてあります
> 💡 **間違えてJSONを丸ごと貼ってしまっても動きます**（自動的に中身を読み取ります）

### ③ GOOGLE_CALENDAR_ID / ④ GOOGLE_SPREADSHEET_ID

上の「おすすめ」の②③と同じです。

## 手順8　動作確認

`MOCK_MODE` を触る必要はありません。
**Google の認証情報を登録した時点で、カレンダー連携は自動的に有効になります。**

パソコンで動かしている場合は、サーバーを起動し直してください。

```bash
npm run dev
```

### 確認すること

1. 管理画面（`https://（あなたのURL）/admin`）を開きます。
2. 管理画面にログインします。
3. 上部の「準備中の項目」から
   **「Google カレンダー未連携」「メモリに一時保存」の行が消えていれば成功**です。
4. **設定** → いちばん上の **接続を確認する** を押します。
   【Google】の行がすべて ✅ になっていれば成功です。
   ❌ の行には「→」で直し方が表示されます（JSON の貼り間違い・
   `private_key_id` の取り違え・共有権限の不足などを名指しで教えてくれます）。
5. **予約一覧** → **手動で予約を登録** から、テストの予約を1件入れてみます。
6. Google カレンダーを開き、
   `ビューティーサロン703予約｜○○` という予定ができていれば成功です
   （お客様の名前・電話番号はカレンダーには書き込まれません）。
7. スプレッドシートを開き、`reservations` というタブに
   1行追加されていれば成功です。
8. 確認できたら、そのテスト予約はキャンセルしてください
   （カレンダーからも自動で消えます）。

## うまくいかないとき

| 症状 | 原因と対処 |
| --- | --- |
| 「Google 認証に失敗しました」 | `GOOGLE_PRIVATE_KEY` の貼り付けミス。`-----BEGIN` から `-----END PRIVATE KEY-----` まで全部入っているか確認してください |
| 「Google API エラー（events.insert / HTTP 404）」 | `GOOGLE_CALENDAR_ID` が違います。手順5で確認し直してください |
| 「Google API エラー（events.insert / HTTP 403）」 | カレンダーの共有権限が「閲覧」になっています。**予定の変更権限**に変更してください |
| 「Google API エラー（values.append / HTTP 403）」 | スプレッドシートの共有が「閲覧者」になっています。**編集者**に変更してください |
| カレンダーに何も出ない | Vercel で **Redeploy** したか確認してください（環境変数は登録しただけでは反映されません） |
| 「Google 認証に失敗しました」が消えない | 秘密鍵の貼り付け漏れです。`-----END PRIVATE KEY-----` まで入っているか確認してください |

まずは管理画面の **設定 → 接続を確認する** を押してください。どこで止まっているかと直し方が表示されます。

さらに詳しい記録は次の場所にあります。

- **Vercel の場合** … プロジェクト → **Logs**（または Deployments → 対象 → Runtime Logs）
- **パソコンの場合** … サーバーを起動しているターミナル

## 覚えておきたい便利な使い方

設定が終わると、次のことが**Googleカレンダーを操作するだけ**でできます。

| やりたいこと | カレンダーでの操作 |
| --- | --- |
| その時間を予約不可にする | 普通に予定を入れる（例: 15:00-17:00「私用」） |
| その日を丸ごと休業にする | **終日**の予定を入れる（例:「休業」） |
| 予定はあるが予約は受けたい | 予定の「予定あり」を **「予定なし」** に変更する |

管理画面を開かなくても、いつものカレンダーで休業日を管理できます。

---

## ⚠️ スプレッドシート連携を必ず完了してください

Google カレンダーだけを設定し、スプレッドシート（`GOOGLE_SPREADSHEET_ID`）を
設定していない状態では、**予約データはサーバーのメモリに一時保存**されます。
Vercel ではサーバーが頻繁に入れ替わるため、**予約データが消えてしまいます**。
管理画面の上部に赤字で「メモリに一時保存」と出ている間は、本番運用を始めないでください。

また、スプレッドシートの**予約データが読み取れないときはエラーにして予約を受け付けません**
（空き枠に見えて二重予約になるのを防ぐため）。
メニューや営業時間などの**設定値**が一時的に読めないときだけ、初期値で動き続けます。
